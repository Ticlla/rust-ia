# 📚 Clase 11: Iteradores y Closures Funcionales en Rust para IA

En esta clase aprenderás la programación funcional de alto rendimiento en Rust. Dominarás los tres tipos de iteración (`iter()`, `iter_mut()`, `into_iter()`) y cómo combinarlos con *closures* (`|x| ...`) y adaptadores vectorizados como `.zip()`, `.map()`, `.filter()` y `.sum()` para realizar cálculos sobre tensores sin copias de memoria (*Zero-Cost Abstractions*).
