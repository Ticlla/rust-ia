# 📚 Clase 09: Enums y Pattern Matching (`match`) en Rust para IA

En esta clase aprenderás la versatilidad de los tipos algebraicos (*Enums*) en Rust. A diferencia de C o Java, los Enums de Rust pueden contener datos asociados en cada variante, y combinados con `match` exhaustivo permiten modelar estados de entrenamiento, arquitecturas y tipos de capas sin fallos silenciosos.
