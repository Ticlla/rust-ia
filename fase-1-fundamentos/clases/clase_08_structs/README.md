# 📚 Clase 08: Structs y Métodos (`impl`) en Rust para IA

En esta clase aprenderás cómo encapsular el estado y el comportamiento de componentes de Machine Learning mediante estructuras (`struct`) y bloques de implementación (`impl`). Comprenderás constructores idiomáticos como `new()` y la diferencia crucial entre métodos de consulta (`&self`) y métodos de optimización (`&mut self`).
